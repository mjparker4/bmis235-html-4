    Selector rules, all in one place
    
    
      
  • Tag: the tag name with no brackets. p picks every paragraph.
    • 
      
  • Class: a period and the class name. .note picks everything with class="note", on any tag.
    • 
      
  • ID: a # and the id. #main-title picks the one element with id="main-title".
    • 
      
  • Tag and class together: no space. p.note picks only paragraphs with the note class.
    • 
      
  • Inside something: a space means "inside." nav a picks links inside the nav, not links anywhere else.
    • 
      
  • Several at once: a comma. h1, h2 picks every h1 and every h2.
    • 
      
  • CSS selectors never use angle brackets: write p, not <p>.
