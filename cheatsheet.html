Cheat Sheet

The main rules from HTML-1 to HTML-3. Practice selectors in the Selector Lab, or paste this page into the Notes Quiz to test yourself.

HTML-1 · Tags and page structure

  • A tag is a label in angle brackets, like <p>. Most come in pairs: an opening tag and a closing tag with a slash, like <p>...</p>.
  • An element is the opening tag, its content, and the closing tag together.
  • An attribute adds information inside an opening tag, like href="quiz.html".
  • <!DOCTYPE html> goes on the very first line.
  • The <head> holds information about the page that visitors don't see on the page itself: the <title> (shown in the browser tab), <meta> tags, and the link to the stylesheet.
  • The <body> holds everything visitors see: headings, paragraphs, images, links.
  • <h1> is the main heading. <p> is a paragraph.
  • A comment, <!-- like this -->, is a note in the code that the browser doesn't show.
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="author" content="Matthew Parker">
  <title>Shows in the tab</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <h1>Shows on the page</h1>
  <p>So does this.</p>
</body>
</html>

HTML-2 · Links, images, and paths

  • <a href="..."> makes a link. The href says where it goes.
  • <img src="..." alt="..."> shows an image. The src says where the file is. The alt text describes the image for screen readers and shows up if the image can't load. <img> has no closing tag.
  • A relative path starts from the folder of the page you're editing:
    • Same folder: just the file name, quiz.html
    • Into a folder: folder, slash, file, img/home.png
    • Up a folder: ../ first, ../styles.css
  • An absolute URL is a full web address, like https://www.gonzaga.edu. Use it for other people's sites.
  • Capital letters count on live web servers: Home.png and home.png are different files.
  • Use forward slashes /, don't start a path with /, and match the file extension exactly (.html isn't .htm).
<a href="quiz.html">Notes Quiz</a>
<img src="img/home.png" alt="Home">
<a href="https://www.gonzaga.edu">Gonzaga</a>

HTML-3 · CSS and the stylesheet

  • CSS controls how a page looks: colors, fonts, sizes, spacing.
  • A stylesheet is a separate .css file. Every page that links to it with <link rel="stylesheet" href="styles.css"> in its <head> gets the same styles, so changing one rule changes the whole site.
  • A CSS rule has a selector (what to style), then properties and values inside curly braces. Each line ends with a semicolon.
  • A class selector starts with a period, like .cs-box. It's more specific than a tag selector like p.
  • The cascade decides which rule wins when two rules style the same thing: the more specific selector wins, and if they're equally specific, the one that comes later wins.
  • A hex color is # plus six digits or letters, like #0077B6.
h1 {
    color: #0077B6;
    font-size: 40px;
}
