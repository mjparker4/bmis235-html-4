    The rules, all in one place
    • A path starts from the file you're editing. The browser starts in the folder that holds the current page, then follows the path from there.
    • Same folder: just the file name. From index.html to the Kalbi page: kalbi.html
    • Into a folder: folder name, a slash, then the file. From index.html to an image: img/kalbi.png
    • Up a folder: ../ means "go up one level." From recipes/spam-musubi.html back to the stylesheet: ../styles.css
    • Capital letters count. GitHub Pages and Cloudflare treat Kalbi.png and kalbi.png as different files. Your laptop usually doesn't, so a path can work when you test it at home and break once it's live.
    • Use forward slashes / in web paths, never the Windows backslash \.
    • Don't start with /. A leading slash jumps to the top of the whole domain, not your project folder. On GitHub Pages your site sits in a subfolder (username.github.io/bmis235-html-4/), so /img/kalbi.png looks in the wrong place.
    • Spell the extension exactly. kalbi.htm and kalbi.html are two different files, and so are .png and .jpg.
